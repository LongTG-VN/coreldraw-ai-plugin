## KNOWN LIMITATIONS

- The API is local and unauthenticated; it must remain on `127.0.0.1`.
- The COM lock is process-local. Multiple API processes are unsafe against one
  active Corel document.
- Safe lifecycle endpoints require absolute paths and existing parent folders;
  legacy file endpoints remain for compatibility and are less strict.
- There is no dedicated public close-document endpoint; the runbook uses
  open/save lifecycle and real smoke used direct integration-layer COM.
- Corel rollback depends on Corel successfully ending and undoing a command
  group; the transaction report exposes failures rather than claiming atomicity.
- The Qwen adapter still relies on deterministic schema recovery and remains
  research-only due to training/reference lineage.
